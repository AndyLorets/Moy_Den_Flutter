# UI/UX Design Document — Мой день
> Принципы интерфейса · Dashboard · ReflectionScreen · 2026

---

## Главный принцип

> **Интерфейс должен считываться за долю секунды — как хорошая тактическая панель.**

Чистый, плоский, профессиональный. Никакой перегрузки — только то, что нужно прямо сейчас.

---

## Dashboard — структура экрана

Поток сверху вниз, без прыжков по экрану:

```
Дата · Приветствие                    [🔥 стрик]
──────────────────────────────────────────────
○ Обычное  😴 Усталость  🌬️ Тревога  ⚡ Воодушевление
──────────────────────────────────────────────
Energy Bar  «Запас сил: 72%»
──────────────────────────────────────────────
Карточка «Следующий шаг»
──────────────────────────────────────────────
[Все задачи]  [Рефлексия]
                                    FAB «Мне тяжело»
```

---

### 1. Шапка (Header)

Задаёт контекст, не перегружает.

| Элемент | Описание |
|---|---|
| Дата и день недели | Всегда видны в верхней части |
| Приветствие | Меняется по времени суток (утро / день / вечер) |
| Стрик 🔥 | Счётчик дней подряд — якорная мотивация |

---

### 2. Выбор состояния (inline)

4 чипа в одну строку — прямо под шапкой. Пользователь не «прыгает» по экрану.

| Состояние | Иконка | Влияние на систему |
|---|---|---|
| Обычное | ○ | Лимит 100%, множитель ×1.0 |
| Усталость | 😴 | Лимит 40%, множитель ×1.5, только P0 |
| Тревога | 🌬️ | Лимит 60%, множитель ×1.2, только isMechanical |
| Воодушевление | ⚡ | Лимит 120%, множитель ×0.8, бонусная задача |

- Выбранный чип подсвечивается цветом состояния
- При смене состояния мгновенно пересчитывается Energy Bar и список задач

---

### 3. Energy Bar — главный индикатор

Ядро интерфейса. **Полностью заменяет** классический прогресс-бар выполненных задач.

- Заполнение = оставшийся запас сил пользователя
- Подпись: `«Запас сил: 72%»` — без технических терминов

**Цветовое кодирование (строгое):**

| Уровень | Диапазон | Цвет | HEX |
|---|---|---|---|
| Высокий | > 60% | Зелёный | `#27AE60` |
| Средний | 30–60% | Жёлтый | `#F39C12` |
| Низкий | < 30% | Красный | `#E74C3C` |

---

### 4. Точка фокусировки (Main Action)

Центральный интерактивный элемент. Не даёт пользователю распыляться.

**Карточка «Следующий шаг»:**
- Формируется с учётом текущего состояния (StateConfig)
- Реализует главный принцип приложения:

> **Показывать только одно следующее действие — то, которое нужно сделать прямо сейчас.**

---

### 5. FAB «Мне тяжело» — глобальный элемент

- Floating Action Button, присутствующий на **каждом экране**
- Открывает протокол поддержки: дыхание + микро-задача + текст опоры
- Всегда доступен — независимо от состояния и текущего экрана

---

## ReflectionScreen — экран рефлексии

Открывается по кнопке «Рефлексия» с Dashboard. Содержит контекстные поля в зависимости от фазы дня.

### Утро (5:00–11:00)

| Блок | Описание |
|---|---|
| **Зачем я это делаю** | Текстовое поле — смысл и мотивация дня |
| **Конфликт бессознательного** | Выбор из вариантов: согласие / конфликт / нейтраль |

### День (11:00–18:00)

| Блок | Описание |
|---|---|
| **Зачем я это делаю** | Текстовое поле |
| **Из какого состояния действовал?** | Выбор: из страха / из свободы |

### Вечер (18:00+)

| Блок | Описание |
|---|---|
| **Аффирмация** | Фиксированный текст поддержки |
| **Что не сделал из-за страха** | Текстовое поле |
| **Инсайт дня** | Текстовое поле |

---

## Визуальные принципы

- **Плоский дизайн** — минимум теней, максимум воздуха
- **Иерархия через размер и цвет**, а не через декор
- **Один фокус на экране** — пользователь не должен выбирать, куда смотреть
- **Поток сверху вниз** — все действия в одной зоне, без прыжков
- Все тексты — **на русском**, без системных английских фраз
